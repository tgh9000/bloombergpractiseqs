PR: Add dice outcome counter for the probability module
Summary
This change adds num_rolls_to_target(n, k, target), which counts how many ways n fair dice, each with faces numbered 1 through k, can be rolled so that the face values add up to target.

Expected behavior
n, k and target are integers with 1 <= n <= 30, 1 <= k <= 30 and 1 <= target <= 1000.
Every face from 1 to k inclusive is a possible outcome for every die.
Dice are distinguishable, so rolls that differ in order are counted separately (for example, two dice showing (1, 6) and (6, 1) are two different ways).
Because the count can be very large, the result must be returned modulo 10^9 + 7.
If target cannot be reached (target < n or target > n * k) the function returns 0.
The result is always an integer in the range [0, 10^9 + 6].
The solution should run in roughly O(n * k * target) time or better.
Review task
Review the proposed implementation and its tests against the behavior above. Make the necessary corrections in the implementation and tests. Run the test suite and explain which cases give you confidence in the result.
