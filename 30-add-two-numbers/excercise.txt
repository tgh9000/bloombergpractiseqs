PR: Add big-number addition for linked digit lists (least significant digit first)
Summary
This change adds add_two_numbers(l1, l2). Each argument is a singly linked list of ListNode objects representing a non-negative integer, with the digits stored in reverse order: the head node holds the ones digit. The function returns a new linked list, in the same format, representing the sum.

Expected behavior
Each list contains between 1 and 100 nodes, and every node value is a single digit from 0 to 9.
Inputs have no leading zeros, except for the number 0 itself, which is a single node with value 0.
The lists may have different lengths.
The result is the sum, least significant digit first, with no leading zeros.
Carries must propagate correctly through every digit, including through the remaining digits of the longer list and into a new final digit (for example 99 + 1 gives 0 -> 0 -> 1).
The input lists must not be modified.
The result must be built from new nodes; it must not share any nodes with either input.
Review task
Review the proposed implementation and its tests against the behavior above. Make the necessary corrections in the implementation and tests. Run the test suite and explain which cases give you confidence in the result.
